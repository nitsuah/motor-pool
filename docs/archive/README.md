# Historical documentation

Files in this directory preserve prior plans, migration records, audits, demo
scripts, and handoffs. They are useful for project history, but their commands,
service names, hardware assumptions, and completion status may no longer match
the current checkout. Do not use them as setup instructions without checking
the current docs and implementation.

Use these current sources for operational guidance:

- [README](../../README.md) for the current quick start, services, and model setup.
- [Deployment](../DEPLOYMENT.md) for Compose profiles, configuration, and runtime checks.
- [API](../API.md) for current routes and event contracts.
- [Features](../FEATURES.md), [Roadmap](../ROADMAP.md), and [Tasks](../TASKS.md) for current product state and planned work.
- [Metrics](../METRICS.md) for measurements tied to the current machine and date.

Some archived pages retain their own notices where a specific warning matters.
